# Paket UAV Single-EDF (digital)

- `wiring/wiring_diagram.png|svg|pdf`: wiring diagram yang sudah dikoreksi (dibuat dengan wiring/make_wiring.py)
- `wiring/wiring_connections.csv`: tabel koneksi dengan dua sumber per koneksi dan status verifikasi
- `wiring/KOMPONEN_KURANG.md`: apa yang masih kurang di daftar komponen
- `sitl/`: backend fisika JSON untuk ArduPilot SITL, parameter, self-test (baca sitl/README_SITL.md)
- `PANDUAN_PERBAIKI_ASSEMBLY.md`: cara menyatukan UAV di Inventor, ukuran asli CAD, STL vs STEP, mengisi vehicle.json
- `inventor/`: uav_transforms.csv (posisi terpasang dari SLDASM) dan snap_to_sldasm.iLogicVb (BELUM diuji di Inventor)
- `UPDATE_CAD.md`: edit CAD yang harus dilakukan
- `uav_calc.py`: kalkulasi daya, endurance, torsi vane, surya
